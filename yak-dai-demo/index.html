It arrives as one long markdown file. You skim the headings, trust it, and find out what was wrong three days into the work.

# Plan: Ship the v1 mobile app

## Task: Set up iOS release signing
### Problem
Release builds are signed from one laptop,
so nobody else can cut a build.
### What to do
Create a distribution certificate in the
shared Apple team, store it with
`fastlane match`, put the API key in CI.
### Expected outcome
Any CI runner can sign a release build.

## Task: Add the iOS release lane to CI
### Problem
iOS archives are produced by hand, so a
shipped binary depends on whatever Xcode
that laptop had.
### What to do
Add a `release_ios` lane in the Fastfile
that fetches certificates, sets the build
number from the CI run, then uploads.
### Expected outcome
Pushing a tag produces a signed build.
